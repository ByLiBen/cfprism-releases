# cfprism Releases

这是 cfprism 的公开发布仓库，仅用于保存 Windows 离线安装包和自动更新所需的 GitHub Releases。

- 产品源码独立维护，不在本公开发布仓库镜像。
- 发行包：请从本仓库的 [Releases](https://github.com/ByLiBen/cfprism-releases/releases) 下载
- 自动更新：cfprism 桌面程序通过 GitHub Releases API 检查带 SHA-256 digest 的 `windows-amd64` ZIP

本仓库不镜像产品源码。Release 标签只用于标记公开发行版本。
